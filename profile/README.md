MindsHub brings choice to working and building with AI. Use the models and providers that fit your work, with the freedom to change.

## MindsHub

An open-source agent workspace to research, analyze information, create content, and develop software. Run open-source agent harnesses with your choice of models, on your own infrastructure or in the hosted app.

[Open the workspace](https://console.mindshub.ai/?utm_source=github&utm_medium=org-readme&utm_campaign=mindshub-profile) · [Download or build from source](https://github.com/mindsdb/mindshub#get-started)

## MindsHub Inference

Connect your own agents and products to leading models through one API, with shared controls and billing. Use OpenAI or Anthropic SDKs and switch models as your needs change.

[Explore Inference](https://mindshub.ai/unified-inference?utm_source=github&utm_medium=org-readme&utm_campaign=mindshub-profile) · [API docs](https://docs.mindshub.ai/inference)

## Repositories

| Project | What you'll find |
| --- | --- |
| [MindsHub](https://github.com/mindsdb/mindshub) | The main project for running the complete MindsHub workspace. |
| [Anton](https://github.com/mindsdb/anton) | An open-source agent harness for MindsHub and standalone use in the terminal. |
| [Workspace app](https://github.com/mindsdb/cowork) | The desktop and web interface, built with Electron and React. |
| [Workspace backend](https://github.com/mindsdb/cowork-server) | Projects, conversations, files, scheduling, memory, and agent orchestration. |
| [MindsDB Query Engine](https://github.com/mindsdb/engine) | A standalone SQL engine for live data access and semantic search, maintained by the community. |

## Contribute and connect

Contribute code, integrations, documentation, or bug reports in the relevant repository. For questions and to share what you've built, join [Discord](https://mindshub.ai/discord).

For security issues, follow the reporting guidance in the affected repository's security policy.

## About MindsDB

Founded in 2018 in Berkeley, MindsDB is the company behind MindsHub. Its investors include Benchmark, Mayfield, Y Combinator, and NVIDIA. The original open-source query engine also keeps the MindsDB name.

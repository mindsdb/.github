MindsHub is the platform for open-source AI agents: the place where they live, run, and do real work. At its center is **Cowork**, the unified workspace where knowledge workers delegate entire tasks — research, analysis, reporting, scheduled operations — and collect finished, shareable results.

> **Delegate anything. It comes back done.**

## Start here

- **Use Cowork on the web** — nothing to install: **[console.mindshub.ai](https://console.mindshub.ai/?utm_source=github&utm_medium=org-readme&utm_campaign=mindshub-profile)**.
- **Get the desktop app** — [macOS](https://downloads.mindsdb.com/mindshub-cowork/mac/mindshub-cowork-latest.pkg) · [Windows](https://downloads.mindsdb.com/mindshub-cowork/windows/mindshub-cowork-latest.exe).
- **Run it open source** — clone the [platform](https://github.com/mindsdb/minds) and `make setup && make dev`.

Plans and what's included are on the **[pricing page](https://mindshub.ai/pricing?utm_source=github&utm_medium=org-readme&utm_campaign=mindshub-profile)**.

## Repositories

Our main repositories:

- **[MindsHub Cowork Platform](https://github.com/mindsdb/minds)** — the superproject that assembles the full open-source stack (the agent, the app, and model routing) so you can build and run it all from source, anywhere.
- **[Anton](https://github.com/mindsdb/anton)** — the self-improving open-source agent that powers Cowork as the default harness, and runs standalone in your terminal.
- **[Cowork Server](https://github.com/mindsdb/cowork-server)** — Cowork's backend: orchestrates projects, conversations, files, scheduling, memory, and agents.
- **[Cowork App](https://github.com/mindsdb/cowork)** — Cowork's desktop and web client (Electron + React); the workspace you interact with.
- **[MindsDB Query Engine](https://github.com/mindsdb/engine)** — a standalone, open-source query engine: ask 200+ data sources in one SQL dialect, with no ETL. The original MindsDB (pre-2026 rebrand), maintained as its own project.

## Contributing
